# Money 中文介绍

Money 是一个用于 [Flarum](https://flarum.org) 的虚拟货币 / 积分扩展。它可以给社区用户增加 `money` 余额，并围绕注册、发帖、回复、点赞、内容隐藏或删除、管理员手动修改等行为生成完整的积分变动记录。

当前 `2.x` 版本面向 Flarum 2.x beta 适配：

- Flarum：`^2.0.0-beta`
- PHP：`^8.3`
- 依赖 `flarum/likes`：`^2.0@beta`
- Flarum 1.x 用户建议继续使用 `0.x` 版本线。

本扩展基于 [AntoineFr/flarum-ext-money](https://github.com/AntoineFr/flarum-ext-money) 修改而来。感谢原作者提供的优秀基础版本。本版本在原有虚拟货币能力上补充了更细的积分记录、回馈作者、字数规则和 Flarum 2.x 兼容。

## 主要功能

### 用户积分余额

- 为每个用户增加积分余额。
- 在用户卡片中展示积分。
- 支持自定义积分名称，例如 `[money] 积分`。
- 可以选择余额为 0 时不展示。

### 积分变动记录

- 每次积分变化都会记录到 `money_logs` 表。
- 记录内容包括变动数量、变动后余额、动作类型、原因、关联用户、关联帖子、关联讨论和时间。
- 在用户个人页增加“积分记录”入口。
- 当前前台页面只允许用户查看自己的积分记录。
- 积分记录支持分页加载。
- 记录原因会尽量链接回对应讨论或帖子。

### 注册初始积分

- 可以设置新用户注册后的初始积分。
- 初始积分同样会写入积分记录。

### 发帖和回复积分

- 可以分别设置创建主题首帖和回复讨论时的积分变动。
- 每种行为都可以配置为“奖励”或“扣除”。
- 如果扣除积分时用户余额不足，会阻止该操作并提示余额不足。
- 回复可以结合最小字数规则使用。

### 回复回馈作者

- 回复规则支持“回馈作者”。
- 适合“回复者支付积分，主题作者获得积分”的社区机制。
- 用户回复自己的主题时不会给自己产生回馈。

### 点赞积分

- 可以设置点赞帖子时的积分变动。
- 点赞可以配置为奖励，也可以配置为扣除。
- 当点赞配置为扣除时，可以选择把扣除的积分回馈给帖子作者。
- 用户给自己的帖子点赞不会产生积分变化。
- 取消点赞会撤销对应的积分效果。

### 超出字数后的额外积分

- 可以设置字数阈值、字数增量和每次增量对应的积分。
- 内容超过阈值后，每达到一次增量就追加一次积分变动。
- 额外积分会跟随发帖或回复当前配置的方向：奖励或扣除。
- 额外积分变化也会写入积分记录。

### 管理员手动修改

- 提供 `编辑货币` 权限。
- 有权限的管理员可以从用户操作菜单修改用户积分。
- 手动修改会计算差值并写入积分记录。

### 内容隐藏、恢复和删除后的自动调整

- 可以配置隐藏 / 恢复内容时自动更新积分。
- 也可以配置只在删除内容时更新积分。
- 如果不需要自动调整，可以关闭。
- 这些变化会记录关联的帖子或讨论上下文。

### 多级货币展示

- 可以设置多个等级名称，例如 `金豆,银豆,铜豆`。
- 可以设置进制，例如 `100`。
- 扩展会把一个数值余额拆分成多个等级单位展示。

## 后台配置项

| 配置项 | 说明 |
| --- | --- |
| 货币名称 | 积分展示模板，用 `[money]` 作为数值占位符。 |
| 新用户初始资金 | 新用户注册后获得的初始积分。 |
| 货币等级名称 | 多级货币展示名称，使用英文逗号分隔。 |
| 货币进制 | 多级货币拆分时使用的进制。 |
| 新帖变动金额 | 创建主题首帖时变动的积分数量。 |
| 回复变动金额 | 回复讨论时变动的积分数量。 |
| 点赞帖子变动金额 | 点赞帖子时变动的积分数量。 |
| 积分变动类型 | 可选择奖励或扣除。 |
| 是否回馈作者 | 回复或点赞规则是否把积分回馈给原作者。 |
| 字数阈值 | 超过该字数后开始计算额外积分。 |
| 字数增量 | 超过阈值后每多少字触发一次额外积分。 |
| 每次变动积分 | 每次字数增量对应的积分数量。 |
| 自动更新货币 | 配置隐藏 / 恢复 / 删除内容时如何调整积分。 |
| 如果值为零则不显示 | 用户积分为 0 时隐藏展示。 |

## 安装

使用 Composer 安装：

```sh
composer require shebaoting/money:"^2.0"
```

执行数据库迁移并清理缓存：

```sh
php flarum migrate
php flarum cache:clear
```

然后到 Flarum 后台启用扩展，配置权限和积分规则。

## 更新

```sh
composer update shebaoting/money:"^2.0"
php flarum migrate
php flarum cache:clear
```

如果从 `0.x` 升级到 `2.x`，请先确认论坛已经升级到 Flarum 2.x beta，并且运行环境满足 PHP 8.3 或更高版本。

## 设计想法

这个积分系统的设计想法，是把社区里的“时间”和“注意力”变成可感知的东西。

一个人发帖、回复、点赞，都会消耗时间。如果付出没有得到任何回应，这种时间成本就容易被忽略。通过积分，社区可以把这些行为之间的成本、奖励和回馈显性化，让内容生产者、回复者和读者之间形成更清晰的价值流动。

类似的概念可以参考电影 _In Time_。
